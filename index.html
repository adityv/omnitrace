The open-source, privacy-first AI log debugger. OmniTrace watches your logs, removes secrets automatically, and explains failures while you stay in control.

Install OmniTrace See how it works
Terminal
$ npm install -g omnitrace
01

Watch in real time

Tail any application log and capture the surrounding context whenever an error, exception, or fatal event appears.

02

Scrub before sharing

Emails, IP addresses, cloud keys, tokens, passwords, cards, and JWTs are redacted before the AI sees your logs.

03

Explain and fix

Route sanitized context to OpenAI or keep everything on-device with a local Ollama model.

Privacy by default

Your logs are not training data.

OmniTrace is designed around a simple boundary: sensitive values are scrubbed locally before a cloud request is made. If you need zero network exposure, use Ollama and keep analysis on your machine.
