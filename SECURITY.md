# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Contact the maintainer through the private contact options available from [github.com/adityv](https://github.com/adityv), including a concise reproduction, affected version, impact, and a sanitized proof of concept.

Never send API keys, passwords, production logs, personal data, or other live credentials in a report.

## Scope

Security reports are especially relevant to secret sanitization, configuration-file permissions, provider routing, path handling, dependency vulnerabilities, and accidental disclosure of log contents.

## Supported versions

The latest release on the `main` branch is the supported development target. Users should keep OmniTrace and its dependencies updated before using it with sensitive production logs.
